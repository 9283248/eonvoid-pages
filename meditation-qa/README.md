# 🎧 medqa — проверка качества AI-озвучки медитаций

Инструмент «слушает» готовую озвучку (Fish Audio и любой другой TTS) и
**указывает с таймкодами** на проблемные места: писк/срыв голоса, артефакты и
щелчки, скачки громкости, слишком эмоциональные фразы, подозрительно длинные
паузы. Дополнительно умеет **сверять озвучку с исходным текстом** (пропущенные и
перевранные слова) и **проверять сам текст** до синтеза (пробелы, пунктуация,
латиница, числа, ударения).

Цель — не заменить финальное прослушивание, а сузить его: вместо «слушать 20
минут целиком» вы получаете список меток `[02:14] возможный писк` и проверяете
точечно.

## Быстрый старт

```bash
cd meditation-qa
pip install -r requirements.txt        # достаточно numpy для базового анализа

# 1) Только звук — работает сразу, без тяжёлых моделей
python -m medqa моя_медитация.wav

# 2) Демо на синтетическом файле с дефектами
python examples/make_test_wav.py
python -m medqa examples/test_defective.wav
```

Формат аудио: `.wav` из коробки. Для `.mp3/.m4a/.ogg` — `pip install soundfile`
или сконвертируйте: `ffmpeg -i in.mp3 out.wav`.

## Что и как ловится

| Ваша проблема | Что делает medqa | Трек |
|---|---|---|
| Голос уходит **в писк** | скачок основного тона F0 выше обычного диапазона голоса | звук |
| **Артефакты / щелчки / склейки** | резкие спектральные скачки (spectral flux) вне границ фраз | звук |
| **Клиппинг** (перегруз) | сэмплы на пределе амплитуды | звук |
| **Скачки громкости** / крик | выбросы RMS относительно средней | звук |
| Говорит **слишком восхищённо** | фразы с аномально высоким тоном/размахом/темпом на фоне спокойной медитации | звук |
| Пропал кусок → **длинная пауза** | тишина длиннее порога | звук |
| **Пропущенные / лишние / перевранные слова** | расшифровка Whisper ↔ diff с текстом | содержание |
| **Пропущенный пробел / запятая**, слипшиеся слова, латиница, числа | регэкспы по исходному тексту | текст |
| **Неправильные ударения** | расстановка ударений RUAccent в тексте *до* синтеза | текст |

Все акустические пороги **адаптивные**: считаются по самой дорожке (медиана +
MAD), поэтому подстраиваются под конкретный голос без ручной калибровки.

## Сверка с текстом (ловит пропуски слов и ошибки чтения)

Нужен Whisper. Рекомендуется `faster-whisper`:

```bash
pip install faster-whisper
python -m medqa моя_медитация.wav --script сценарий.txt --transcribe
```

Whisper расшифровывает озвучку с таймкодами по словам, а diff со сценарием
показывает: `[01:03] Пропущено при озвучке: «умиротворение»`.

## Проверка текста до синтеза (самое дешёвое — делайте всегда)

Многие ошибки (пробелы, запятые, ударения) дешевле починить **в тексте**, а не
искать потом в звуке:

```bash
python -m medqa --script сценарий.txt --check-text
pip install ruaccent   # для ударений
python -m medqa --script сценарий.txt --check-stress
```

RUAccent проставляет ударения — **скармливайте в Fish Audio уже размеченный
текст**, и ошибок ударения станет заметно меньше.

## Машинный отчёт (для скриптов и CI)

```bash
python -m medqa audio.wav --json report.json
```

JSON содержит массив `findings` с полями `t_start`, `t_end`, `track`, `kind`,
`severity`, `message`. Код возврата `1`, если что-то найдено, `0` — если чисто
(удобно как гейт перед публикацией).

## Как это устроено

```
medqa/
├── audioio.py    # загрузка WAV (стандартный wave) → моно float32
├── features.py   # покадровые признаки: F0, RMS, ZCR, спектр. центроид, flux
├── analyze.py    # детекторы аномалий (адаптивные пороги)
├── textcheck.py  # проверка исходного текста + опц. ударения (RUAccent)
├── transcript.py # опц. Whisper + выравнивание с текстом
├── report.py     # единый отчёт (текст/JSON)
└── cli.py        # точка входа
```

## Ограничения и что можно усилить

- **Ударения из аудио** напрямую не детектируются надёжно — это делается
  профилактикой в тексте (RUAccent). Флаг «прочитано иначе» из трека содержания
  косвенно ловит и часть ошибок ударения.
- **Слипшиеся слова строчными** (`теломягко`) требуют словаря — можно добавить
  `pyspellchecker`/`hunspell` в `textcheck.py`.
- **Оценка натуральности (MOS)** — можно подключить [NISQA](https://github.com/gabrielmittag/NISQA)
  или [UTMOS](https://github.com/sarulab-speech/UTMOS22) как ещё один детектор
  качества по сегментам.
- Пороги детекторов вынесены в код (`analyze.py`) — при необходимости подстройте
  под свой голос.
