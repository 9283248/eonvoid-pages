Фыва
Слепой метод печати для тех, кто пишет

«Фыва» — приложение для macOS, которое учит печатать десятью пальцами вслепую на русской раскладке ЙЦУКЕН. Курс из 28 уроков заканчивается не тестом на скорость, а знаками писателя и целыми абзацами русской классики.

Бесплатно, без рекламы, без подписки, полностью офлайн.

Fyva is a macOS app that teaches Russian touch typing (ЙЦУКЕН layout). Free, no ads, no subscriptions, fully offline. The interface and the whole course are in Russian.
