How PosterTile works

1. Pick a photo (or type a banner text). 2. Choose the sheet grid — the app shows the real assembled size. 3. Create the PDF and print it at 100% scale. 4. Trim along the crop marks, align the glue strips, done.

My sheets don't line up

This is almost always the printer scaling pages down. In the print dialog make sure Scale is 100% (never "fit to page"). Use Test page in the app: print it and check the ruler measures exactly 10 cm.

Where is my PDF?

Use Share PDF to save it to Files, AirDrop it to a computer, or send it to any printing service.
